📚 Library Management System (Python Mini Project)
A menu-driven Library Management System built using Python basics. This project demonstrates core Python concepts such as dictionaries, functions, loops, and conditional statements through a real-world use case.

🚀 Project Overview
The Library Management System allows a librarian/admin to manage books efficiently. Users can log in, view available books, add new books, issue and return books, and track issued books with borrower details.
This project is designed as a beginner-friendly Python mini project without using external libraries or databases.

🛠️ Features
🔐 Login System
Predefined usernames and passwords
Maximum of 3 login attempts

📖 View All Books
Displays title, author, and availability status

➕ Add New Books (with uploading time)
Prevents duplicate book entries

📤 Issue Books
Checks availability before issuing
Records the name of the person who issued the book

📥 Return Books
Marks issued books as available again

📋 View Issued Books
Lists all currently issued books with borrower names

📟 Menu-Driven Interface
User-friendly command-line menu

▶️ How to Run the Project
Make sure Python 3 is installed on your system.
Run the program:
python library_management.py
